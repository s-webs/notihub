# Технические риски

Наблюдения по коду на 01.11.2026; это не список зарегистрированных инцидентов.

| Приоритет | Наблюдение | Практическое следствие |
| --- | --- | --- |
| Высокий | `EventIdempotency` записывается после создания логов и заданий без общей транзакции. | Одновременные запросы с одинаковым ключом или сбой посередине могут дать дубли/частичную постановку. Сериализовать повторы у источника; для строгой гарантии нужен резерв ключа и outbox. |
| Высокий | Telegram может принять сообщение раньше, чем PostgreSQL сохранит `SENT`. | При повторе задания возможно второе сообщение. Доставка имеет практическую семантику at least once. |
| Высокий | `/queues` и `/docs` открыты без Basic Auth админки. | Ограничивать доступ на reverse proxy и в сети. |
| Средний | При `matched: 0` ответ всё ещё содержит `queued: true`. | Источнику проверять `matched` и `deliveries`, а не только HTTP 200 или `queued`. |
| Средний | Готовый `payload.message`/`text` уходит в Telegram как HTML без экранирования. | Экранировать пользовательские вставки на стороне источника; ошибка разметки может дать `FAILED`. |
| Средний | Админский Basic-пароль закодирован base64 и хранится в `sessionStorage` вкладки. | Использовать HTTPS и ограниченный доступ к админке; base64 не является шифрованием. |
| Средний | Миграция проектных типов копирует прежний общий набор типов в каждый существовавший проект; глобальный админский API типов удалён. | Перед применением миграции оценить объём данных; прямые интеграции со старым `/api/admin/notification-types` перевести на проектный путь. |
| Средний | Seed создаёт демонстрационного бота и маршруты, если не заданы реальные параметры Telegram. | Не запускать seed в рабочей базе без проверки конфигурации. |
| Низкий | Тесты e2e с подменой Prisma не проверяют полный путь PostgreSQL → Redis → Telegram. | При изменениях гарантий доставки дополнять интеграционные проверки с тестовыми зависимостями. |

Резервные копии PostgreSQL содержат токены ботов и потенциально чувствительные поля `notification_logs.request`. Удаление маршрута каскадно удаляет его логи; учитывайте это при расследованиях и требованиях к истории.
