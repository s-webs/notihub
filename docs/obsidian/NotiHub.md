# NotiHub

Сервис принимает события по HTTP, находит проект и его тип уведомления, выбирает маршруты и отправляет сообщения в Telegram через Redis/BullMQ. Настройка проектов, типов и маршрутов выполняется в админке. В коде проект называется `Client`.

## Быстрый путь для интеграции

1. В админке создать проект со стабильным slug.
2. В карточке проекта создать тип уведомления с кодом события.
3. Добавить бота и маршрут для этого типа на нужный `chat_id`/`thread_id`.
4. Из источника отправить `POST /events` с `client`, `type`, `payload` и токеном событий, если он настроен.
5. Проверить `matched > 0`, затем конечный статус доставки в «Логах».

Сервисный URL локального Docker-стека: `http://localhost:3040/`; админка — `/admin/`, Swagger публичного API — `/docs`. Рабочий URL и токен запрашивают у администратора среды. Секреты в заметках не хранить.

Документация отражает рабочее дерево репозитория на 01.11.2026, включая ещё не закоммиченные изменения по проектным типам уведомлений.
